## KORA DATING — VISION ET FLUX MÉTIER (V1)

### 1. Le rôle de Kora

Dans Kora Dating, Kora joue le rôle d'**entremetteur** : son rôle est de **créer des matchs** entre les personnes.

Le processus est volontairement **simple**.

### 2. Inscription

L'inscription se fait en remplissant un formulaire, dans cet ordre :

| # | Information | Règles |
| --- | --- | --- |
| 1 | Prénom | |
| 2 | Âge | |
| 3 | Sexe | |
| 4 | Profession | |
| 5 | Pays et ville de résidence | La personne peut vivre hors du Cameroun : Kora demande donc le pays de résidence, puis la ville. |
| 6 | Photo | Voir la section 3. |
| 7 | Description personnalisée | Texte libre où la personne se présente. Kora l'encourage à écrire une description **pertinente et claire du type d'amour recherché**, car c'est le premier critère de match (section 4). |
| 8 | Où cherchez-vous l'amour ? | Posée une fois la description obtenue. Choix possibles : dans votre quartier, dans votre ville, dans votre pays, à l'extérieur du pays. L'utilisateur peut en choisir **plusieurs**, ou répondre **« peu importe »**. |

Comme pour Housing, l'utilisateur peut donner plusieurs informations dans un seul message. Kora enregistre ce qui a été donné et ne demande que ce qui manque.

### 3. Règle sur la photo

Avant de demander la photo, Kora **précise clairement à l'utilisateur** que :

- la photo ne doit pas être générée par l'IA ;
- **toute photo avec filtre, générée ou modifiée par l'IA entraîne la suppression du compte.**

### 4. Critères de match

| Priorité | Critère |
| --- | --- |
| 1 | **Les descriptions** des deux personnes. |
| 2 | **Filtre sur la localisation** : en plus de la description, Kora filtre les profils selon la localisation (lieu de résidence et réponse à « Où cherchez-vous l'amour ? »). |

### 5. Contrôles obligatoires

Kora doit détecter :

- les **images inappropriées** ;
- les **textes inappropriés** ;
- les **âges inappropriés** : moins de 18 ans ;
- les **images qui ne contiennent pas de personne** ;
- les **images très floues**.
